FREE HOSTING WITH GITHUB PAGES:
1. Sign in or create a free account at https://github.com
2. Create a PUBLIC repository named exactly YOUR-USERNAME.github.io (replace with your GitHub username).
3. Upload index.html, style.css, and script.js to the repository root.
4. Open repository Settings → Pages.
5. Under Build and deployment, select Deploy from a branch; choose main and /(root), then Save.
6. Wait for publishing. Your free URL will be https://YOUR-USERNAME.github.io

Before publishing, replace YOUR-EMAIL@example.com in index.html with your real professional email. Review all wording for accuracy. You can add LinkedIn/social links later.

No paid builder or subscription is required. GitHub Pages hosting is free for public repositories; a custom domain is optional and may cost money.
